# Entrega de PlantLive a Google Play

Archivos preparados:

- `store-listing-es.md`: textos para la ficha y notas de versión.
- `data-safety-es.md`: borrador de Seguridad de los datos.
- `closed-test-plan.md`: recorrido para probadores.
- `release-checklist.md`: control final antes de enviar.

El paquete Android es `es.plantlive.app`, la versión visible es `1.0.0` (`versionCode 2`, para superar las compilaciones locales anteriores) y el proyecto apunta a API 36.

No subas nunca `plantlive-release.jks`, contraseñas, archivos `keystore.properties`, claves de API ni cuentas de revisión a Git.
